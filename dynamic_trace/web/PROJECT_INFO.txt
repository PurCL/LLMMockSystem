🔧 核心功能:

1. CVE列表展示
   - 自动扫描results目录
   - 网格式卡片布局
   - 显示CVE总数统计

2. 实时搜索
   - 支持按CVE ID过滤
   - 键盘快捷键 "/" 快速聚焦

3. CVE详情页
   - 显示所有关联文件
   - 文件大小显示
   - 在线查看JSON文件
   - 文件下载功能

4. JSON查看器
   - 自动格式化
   - 模态窗口展示
   - ESC键关闭
   - 语法高亮

5. RESTful API
   - GET /api/cves
   - GET /api/cve/<cve_id>
   - GET /api/cve/<cve_id>/file/<filename>
   - GET /download/<cve_id>/<filename>
