🚀 启动步骤:

   1. 打开终端，进入项目目录:
      $ cd /home/jian1000/data3/LLMMockSystem/dynamic_trace/web

   2. 启动服务器（两种方式任选其一）:

      方式1 - 使用启动脚本（推荐）:
      $ ./start.sh

      方式2 - 直接运行Python:
      $ python3 server.py

   3. 查看终端输出的URL，例如:
      🌐 Server URL: http://localhost:8000

   4. 在浏览器中打开该URL

   5. 停止服务器:
      按 Ctrl + C
